# Inventory Service (Microservices)

## Overview

This service manages product inventory and provides APIs to check and update stock.

## Tech Stack

* Java
* Spring Boot
* PostgreSQL
* JPA / Hibernate

## Features

* Check product availability
* Reduce stock after order
* Database integration

## API Endpoints

GET /inventory/check
POST /inventory/reduce

## How to Run

1. Start PostgreSQL
2. Create database: inventory_db
3. Run Spring Boot application
